# pi-subagent

同じ Pi profile の Pig と Pi CLI で使える、読み取り専用のサブエージェント。インストール・更新は次のコマンドを実行し、対象のチャットをリロードする。

```sh
pi install git:github.com/cotrin8672/pi-subagent@v1.1.1
```

旧版をインストール済みの場合も、上のコマンドで参照先が切り替わる。`pi update --extensions` だけでは固定されたタグは変わらない。既存の `@ogulcancelik/pi-codex-subagents` とはツール名が重なるため、同時に有効化しない。

親に「AとBを別々のサブエージェントで調べて」と依頼すると、各子が独立した会話で作業する。子には必要な前提を依頼文に含める。親は待たずに作業を続けられ、必要になったら `wait_agent` で結果を取得する。子が完了しても親の会話にメッセージは追加されず、親のモデルも起動しない。

| ツール | 用途 |
|---|---|
| `spawn_agent({task_name,message})` | 子を起動する。親あたり同時4実行まで |
| `send_message({target,message})` | 実行中の子に指示を追加、または完了済みの子の会話を続ける |
| `wait_agent({targets?,timeout_ms?})` | 未読の結果を1件取得する。完了済みなら即時に返し、実行中なら待つ。`timeout_ms: 0` は待たずに確認する。待機の取消は子を止めない |
| `interrupt_agent({target})` | この親の子だけを停止 |
| `list_agents({})` | 子の状態だけを確認 |

`/agents` で子の会話を閲覧できる。閲覧でモデルは動かず、編集内容も保存しない。永続セッションの子は親の履歴ディレクトリ内の `.subagents` にPi標準のJSONLとして保存する。親ランタイムの終了・リロードで実行は停止するが、履歴と完了済みの未読結果は残る。一時セッションの履歴はディスクに残さない。
